# Digital Wardrobe - Frontend

This folder contains two frontend implementations for the Digital Wardrobe project. Please follow the instructions

---

## 🛠 Shared Prerequisites
Before starting either project, ensure you have:
* **Node.js (LTS)**: [Download here](https://nodejs.org/en/download).
* **Git**: For version control.

---

## 🌐 Web App (React + Vite)
**Location:** `/frontend/webApp`  
**Stack:** Vite, React, Material UI, React Router.

### 1. Setup
```bash
# Navigate to the web directory
cd frontend/web-app

# Install dependencies
npm install

# Install UI & Routing
npm install @mui/material @emotion/react @emotion/styled @mui/icons-material react-router-dom
